# Chá de bebê — Luísa & Alice

Página minimalista e responsiva para a lista de presentes do chá de bebê das
gêmeas Luísa e Alice, em 19 de agosto.

## Rodar localmente

Requisitos: Node.js 22 ou mais recente.

```bash
npm install
npm run dev
```

A página ficará disponível em `http://localhost:3000`.

## Publicar

1. Crie um repositório no GitHub e envie todos os arquivos deste projeto.
2. Na Vercel, escolha **Add New > Project** e conecte o repositório.
3. Mantenha as configurações detectadas e clique em **Deploy**.

Os produtos e seus links estão centralizados em `app/page.tsx`. As imagens
ficam em `public/products` e o visual em `app/globals.css`.
